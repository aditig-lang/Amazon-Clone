# 🛒 Amazon Clone

A responsive e-commerce web application inspired by Amazon's interface, built to practice core frontend development and interactive web UI design.

---

## 🌟 Features

* **Responsive Homepage:** Fully custom header, hero banner, product grid cards, and footer modeled after Amazon's UI layout.
* **Product Showcase:** Visual categories highlighting everyday items, tech gadgets, fashion, and home deals.
* **Interactive Cart & UI:** Interactive elements powered by JavaScript for shopping interactions and UI navigation.
* **Clean CSS Styling:** Built using modular flexbox and grid layouts for seamless desktop and mobile rendering.

---

🛠️ Tech Stack
HTML5: Semantic structure for page components and product grids.

CSS3: Custom styles, Flexbox, CSS Grid, and media queries.

JavaScript: Client side interaction.


🚀 Getting Started
Prerequisites
You only need a modern web browser (such as Google Chrome, Mozilla Firefox, or Microsoft Edge) to run this project.

Local Setup
Clone the repository:

Bash
git clone url?id=11.git
cd Amazon-Clone
Open in browser:

Double-click index.html to open it directly in your browser.

Alternatively, if using VS Code, right-click index.html and select "Open with Live Server".
